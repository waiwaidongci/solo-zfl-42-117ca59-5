# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用（配方逻辑在 `recipe-core.js`，需与 `index.html` 同目录）。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。

## 工艺配方版本库

- 配方记录材料、工序（每行一道）和参数（每行 `键=值`），新建即为 v1 草稿。
- 任一旧版（含定稿版）可「复制新版」，自动生成族内递增版本号的草稿。
- 定稿版本只读：界面仅可查看，保存入口隐藏，逻辑层同样拒绝修改；调整需复制新版。
- 任意两版可「比较差异」，按字段（名称/材料/工序/参数逐项/引用/备注）列出不同。
- 版本间可建立引用（编辑草稿时勾选，可跨配方族）。
- 定稿时校验并阻止三类引用异常：自引用、循环引用（给出引用链）、引用未定稿版本。
- 被定稿版本引用的配方不可移除；移除未被引用的版本时，自动清理草稿中对它的引用。
- 支持按材料、状态、参数范围（参数名 + 数值上下限）、引用关系（有/无引用、被引用、与所选版本的引用关系）筛选。
- 数据存于 localStorage（`zfl42Recipes`），随导出 JSON 一并导出。
